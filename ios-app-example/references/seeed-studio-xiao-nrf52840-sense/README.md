# Seeed Studio XIAO nRF52840 Sense Reference Pack

This folder consolidates the Seeed Studio XIAO nRF52840 / Sense documentation, hardware specs, and helper code snippets that we rely on when building the Omi DevKits.

- `wiki.md` – verbatim copy of the “Getting Started with Seeed Studio XIAO nRF52840 Series” guide (features, specs, setup steps, FAQs, resource links).
- `code/` – ready-to-use Arduino/C++ snippets extracted from the guide for Blink, deep sleep power validation, and battery charge current control.

Use this pack as your offline reference when flashing or debugging XIAO-based builds.
